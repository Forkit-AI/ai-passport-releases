# AI Passport Connect releases

Free Founding Beta downloads: https://www.forkit-ai.com/install

`latest.json` is the Ed25519-signed update manifest. Installed apps verify the pinned public key and installer SHA-256 before updating. The signing key is kept only on the release Mac.

Release 0.1.0 supports Apple Silicon Macs with macOS 13.5 or newer. It works without an account; optional accounts are at https://www.forkit-ai.com/sign-in. This beta is not notarized by Apple.
